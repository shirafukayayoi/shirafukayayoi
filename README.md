## Projects

### [Shirafuka-Practice](https://github.com/shirafukayayoi/Shirafuka-Practice)
日常生活で感じた不便を解消するために作った Python / Node.js のツール集です。

- 自然文から予定を解析して Google Calendar に登録
- Google Classroom API を使った課題情報の取得
- BOOK☆WALKER の情報取得・Google Calendar / Sheets との連携
- 読書管理サービス間の操作自動化
- Google Drive のバックアップツール
- GitHub リポジトリの一括取得 など

### [foo_monthly_stats](https://github.com/shirafukayayoi/foo_monthly_stats)
foobar2000 の再生履歴を記録・可視化するコンポーネントです。

- C++17 / SQLite
- 日次・月次・年次の再生統計
- HTML レポート出力
- GitHub Actions による自動ビルド

### [foo_gdrive_stream](https://github.com/shirafukayayoi/foo_gdrive_stream)
Google Drive 上の音源を foobar2000 から扱えるようにするコンポーネントです。

- Google Drive API / OAuth / PKCE
- ローカルキャッシュを利用した再生
- foobar2000 との統合
